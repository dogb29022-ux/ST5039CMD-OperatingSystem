# ST5039CMD-OperatingSystem
This repository contains lecture materials, laboratory exercises, source code examples, assignments, and supplementary resources used throughout the Programming and Operating Systems module.

## Learning Outcomes
1. Develop confidence in writing programs using the C language.
2. Understand key Operating System concepts and internal mechanisms.
3. Examine how software interacts with system resources and hardware.
4. Analyze process execution, memory organization, and resource management.
5. Apply theoretical concepts through hands-on laboratory activities.
